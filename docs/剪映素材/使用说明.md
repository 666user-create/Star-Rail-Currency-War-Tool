## 剪映操作

1. 新建项目，比例 **16:9**
2. 拖入 `无配音-纯画面.mp4`
3. `配音/` 里的文件按时间段拖到音频轨
4. 导入 `字幕.srt`
5. 加 BGM，音量 **15-20%**
6. 导出 1080P / 30fps
