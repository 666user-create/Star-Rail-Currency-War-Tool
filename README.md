# 货币战争桌宠助手

> **非米哈游官方作品**，与 miHoYo / HoYoverse 无关联。本项目为《崩坏：星穹铁道》"货币战争"玩法的第三方同人辅助工具。

一只会阴阳怪气的随宠桌宠（说话痨怪话），附加对战记录能力：

- **桌宠**：点击说话（"老板~"式吐槽）、拖动、右键菜单、开始/结束对局记录、一键启动游戏
- **战绩面板**：突破官方"仅显示 10 条/收藏 20 条"限制，本地无限记录 + 总时长统计 + 阵容/羁绊/段位/时长分析
- **形象**：本机提取的官方随宠模型（软 toon 渲染 + 官方 Cool/Warm Ramp 色带），**模型不随本仓库分发**

## 安装使用

### 方式一：绿色包（推荐给普通用户）

下载 Releases 里的 `货币战争桌宠-x.x.x-win.zip`，解压到任意目录（例如 `D:\StarRailPet`），双击 `货币战争桌宠.exe` 即可。

首次启动会进入**设置向导**（约 1 分钟）：
1. **游戏路径** — 自动探测你本机的《崩坏：星穹铁道》，也可手动选择
2. **截图位置** — 结算截图存放位置，默认在应用目录的 `data\screenshots`
3. **提取模型** — 一键从游戏文件中提取随宠模型，带实时进度

安装包**已内置 Python 运行环境与提取依赖**，不需要你另外安装 Python。

### 方式二：源码运行

```bash
npm install
npm run dev
```

开发命令：`npm run check`（类型检查）、`npm test`（单元测试）、`npm run build`（编译）、`npm run dist`（打 Windows 包）。

## 获取随宠模型（extractor）

绿色包与源码版**都不包含任何游戏模型或贴图**。两种方式获取模型：

- **绿色包**：首次启动向导第 3 步自动完成（推荐）
- **手动运行**（源码版或想重新提取时）：

```bash
pip install UnityPy lz4
python extractor/extract_pet.py            # 自动探测游戏路径
python extractor/extract_pet.py --game "D:\Star Rail\Game"   # 或手动指定
```

提取产物会写入 `data/official_pet/`（绿色包为 userData 目录），重启应用即可看到随宠模型。

> 提取器仅在**本机只读**打开你已安装的游戏数据文件；产物请勿传播或上传。

## 桌宠与动作

官方模型档支持高兴跳、嗷呜吼叫和拜年。保留抬爪/收脚、伏身抬头张嘴、后脚支撑作揖等动作特征，眼神和饰物细节做了简化。

- 单击桌宠：随机播放高兴跳、嗷呜吼叫、拜年中的一个；拖动只移动桌宠。
- 右键 → **选择动作**：指定一个动作；点击本体可打断，不会写入战绩。
- 头顶小计时表：点击圆表开始记录，展开后显示时间；点击停止按钮结束，数字区域只展示时间。记录状态与右键菜单同步。表盘由程序自带，不需要从模型提取。
- 计时表优先在正上方居中并随拖动移动，跳跃时保持稳定；贴顶时自动换侧。气泡显示在旁边并避开计时表，气泡区域可点穿到下方窗口。
- 右键 → **陪伴设置**：快速切换安静模式或暂时收起；双击系统托盘的小脸图标恢复显示。收起不结束正在进行的记录。
- 右键 → **设置**：分别开关待机自动动作和主动台词，调整低/适中/高三档活跃频率；安静模式暂停主动陪伴，仍回应点击和记录操作，关闭后保留原来的偏好。
- 可见待机以约20fps更新，动作约60fps；收起后暂停模型绘制，恢复时重新等待自动陪伴，不补播隐藏期间的动作。
- 开发时打开 `http://localhost:5173/pet-official-preview.html`：可暂停、拖动时间轴和切换视角，放大与实际桌宠共用同一套渲染和动作代码。

局部绑定由代码根据本机模型生成，不需要用户手动编辑模型，不分发修改后的模型。当前绑定适配提取器输出的说怪话模型，不是通用自动绑骨工具；原版骨骼动画与完整表情尚未导入。

## 记录真实对局

**核心流程：计时 → 自己截图 → 粘贴导入 → 核对保存。**

1. **开始计时**：点击头顶秒表，或按 **Ctrl+Shift+F8**（快捷键被占用时用秒表）。
2. **结束计时**：再点一次停止。程序**不会自动截屏**（全屏游戏下自动抓屏会得到黑帧），只冻结本局时长；随后自动打开战绩面板并选中这份待确认草稿。
3. **自己截图**：游戏结算界面用 `Win+Shift+S` 等工具截图（图片进剪贴板）。
4. **粘贴导入**：回到战绩面板按 **Ctrl+V**，或点「粘贴截图」；也可点「导入结算截图」选已有图片文件（PNG/JPG/WebP）。
5. **核对保存**：识别结果只是预填，逐项核对后点「确认并保存」才计入正式战绩。

补充说明：

- 使用 Windows 自带 OCR + 本地头像/羁绊图标模板比对，预填胜负、模式、职级与变化、生命、评分、阵容、羁绊。首次会缓存公开角色与羁绊小图标，之后可离线匹配；**截图全程在本机处理，不上传**。
- **羁绊只识别名称**，数量请按原图手动补充（例如写成 `减益×2`）。
- 已保存的战绩可随时点开详情 →「修改」逐项更正，不是落子无悔。
- 本局时长以**分钟**为单位填写（支持一位小数），内部按秒存储。未知时长不参与总时长/平均统计。
- 计时与草稿可跨重启保留：中途退出游戏未点结束，计时继续累计，下次启动会提示「上一局还在记着」。
- 长局提醒：计时超过 30 分钟、40 分钟各提醒一次，之后每 10 分钟提醒一次（安静模式下不打扰）。
- 详情页的结算原图可点击，用系统看图器打开大图。

## 截图保存位置

默认存在项目文件夹下的 `data/screenshots/`（便携版为应用目录旁的 data），你也可以在 **右键 → 设置 → 截图保存文件夹** 里自定义。

更改目录并保存时，**已有截图会一并迁移过去**，数据库与草稿里的图片引用同步更新，不会断链。

## 已知限制

- 已用公开截图与隔离数据验证识别与保存流程；特殊单位、英文或模糊画面仍可能漏识。截图没有的起止时间/耗时、部分结算后职级不会被推测填入。
- 真实游戏全屏结算、失败/中退画面仍待更多样本验收。
- 打包版没有代码签名，Windows SmartScreen 可能提示"未知发布者"，选择"仍要运行"即可。
