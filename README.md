# 货币战争桌宠助手

> **非米哈游官方作品**，与 miHoYo / HoYoverse 无关联。本项目为《崩坏：星穹铁道》"货币战争"玩法的第三方同人辅助工具。

一只会阴阳怪气的随宠桌宠（说话痨怪话），附加对战记录能力：

- **桌宠**：点击说话（"老板~"式吐槽）、拖动、右键菜单、开始/结束对局记录、一键启动游戏
- **战绩面板**：突破官方"仅显示 10 条/收藏 20 条"限制，本地无限记录 + 总时长统计 + 羁绊/段位/时长分析
- **形象**：本机提取的官方随宠模型（软 toon 渲染 + 官方 Cool/Warm Ramp 色带），**模型不随本仓库分发**

## 获取随宠模型（extractor）

仓库**不包含任何游戏模型或贴图**。请在**你已安装《崩坏：星穹铁道》的本机**上运行提取器：

```bash
pip install UnityPy lz4
python extractor/extract_pet.py            # 自动探测游戏路径
python extractor/extract_pet.py --game "D:\Star Rail\Game"   # 或手动指定
```

提取成功后生成 `assets/official_pet/`（本机生成、已被 git 忽略），重启应用即可看到随宠模型。

> 提取器仅在**本机只读**打开你已安装的游戏数据文件；产物请勿传播或上传。

## 开发运行

```bash
npm install
npm run dev
```
