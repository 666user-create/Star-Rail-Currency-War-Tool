# 货币战争桌宠助手

> **非米哈游官方作品**，与 miHoYo / HoYoverse 无关联。本项目为《崩坏：星穹铁道》"货币战争"玩法的第三方同人辅助工具。

一只会阴阳怪气的随宠桌宠（说话痨怪话），附加对战记录能力：

- **桌宠**：点击说话（"老板~"式吐槽）、拖动、右键菜单、开始/结束对局记录、一键启动游戏
- **战绩面板**：突破官方"仅显示 10 条/收藏 20 条"限制，本地无限记录 + 总时长统计 + 羁绊/段位/时长分析
- **形象**：本机提取的官方随宠模型（软 toon 渲染 + 官方 Cool/Warm Ramp 色带），**模型不随本仓库分发**

## 获取随宠模型（extractor）

仓库**不包含任何游戏模型或贴图**。请在**你已安装《崩坏：星穹铁道》的本机**上运行提取器：

```bash
pip install UnityPy lz4
python extractor/extract_pet.py            # 自动探测游戏路径
python extractor/extract_pet.py --game "D:\Star Rail\Game"   # 或手动指定
```

提取成功后生成 `assets/official_pet/`（本机生成、已被 git 忽略），重启应用即可看到随宠模型。

> 提取器仅在**本机只读**打开你已安装的游戏数据文件；产物请勿传播或上传。

## 开发运行

```bash
npm install
npm run dev
```

## 三个经典动作

官方模型档支持高兴跳、嗷呜吼叫和拜年。保留抬爪/收脚、伏身抬头张嘴、后脚支撑作揖等动作特征，眼神和饰物细节做了简化。

- 单击桌宠：随机播放高兴跳、嗷呜吼叫、拜年中的一个；拖动只移动桌宠。
- 右键 → **选择动作**：指定一个动作，或选「演示三个动作」依次播放；点击本体可打断演示，不会写入战绩。
- 头顶小计时表：点击圆表开始记录，展开后显示时间；点击停止按钮结束，数字区域只展示时间。记录状态与右键菜单同步，已移除本体上的隐形记录区域。表盘由程序自带，不需要从模型提取。
- 计时表优先在正上方居中并随拖动移动，跳跃时保持稳定；贴顶时自动换侧。气泡显示在旁边并避开计时表，气泡区域可点穿到下方窗口。
- 右键 → **陪伴设置**：快速切换安静模式或暂时收起；双击系统托盘的小脸图标恢复显示。收起不结束正在进行的记录。
- 右键 → **设置**：分别开关待机自动动作和主动台词，调整低/适中/高三档活跃频率；安静模式暂停主动陪伴，仍回应点击和记录操作，关闭后保留原来的偏好。
- 可见待机以约20fps更新，动作约60fps；收起后暂停模型绘制，恢复时重新等待自动陪伴，不补播隐藏期间的动作。
- 开发时打开 `http://localhost:5173/pet-official-preview.html`：可暂停、拖动时间轴和切换视角，放大与实际桌宠共用同一套渲染和动作代码。

局部绑定由代码根据本机模型生成，不需要用户手动编辑模型，不分发修改后的模型。当前绑定适配提取器输出的说怪话模型，不是通用自动绑骨工具；原版骨骼动画与完整表情尚未导入。

开发检查：`npm run check`、`npm test`、`npm run build`。测试使用合成模型，不依赖游戏素材。开发预览从本机素材目录按白名单读取，构建禁用 public 目录复制；发布打包仍需排除本地素材目录。

## 记录真实对局（首版）

- 点击头顶秒表开始计时；停留在游戏结算界面后结束，程序只截取鼠标所在显示器的一帧。也可用 **Ctrl+Shift+F8** 开始/结束（快捷键被其他软件占用时仍可使用秒表）。截图时暂时隐藏本工具窗口。
- 右键 → **打开战绩面板** → **导入结算截图**，可导入 PNG/JPG/WebP 的结算或历史截图。导入时长默认为未知，结束时间暂填导入时刻，请按实际对局时间修改。
- 截图先进入**待确认草稿**，对照原图修改后点击**确认并保存**，才计入正式战绩。支持重新截图、换图、重识别、稍后确认和丢弃；原图保存在本机，正式记录详情可查看。
- 使用 Windows 自带 OCR、区域放大识别和本地头像/羁绊模板比对，预填明确胜负、模式、职级与变化、生命、评分和阵容。首次会缓存公开角色与羁绊小图标，之后可离线匹配；截图在本机处理。识别不确定的字段可修改或留空，核对页会列出尚未填写的字段。
- 右键 → **设置** → **新对局的默认赛季**：设置一次，秒表新记录会带入赛季；旧草稿和导入历史图不会被新默认值追填。图片明确显示赛季标题时可直接识别。
- 计时和草稿可跨重启保留；未知时长不按零计入平均。旧演示记录保留在数据库，默认不进入真实列表和统计。

已用公开截图及隔离数据验证识别与保存流程；特殊单位、部分羁绊数量、英文或模糊画面仍可能漏识。截图没有的起止时间/耗时、部分结算后职级不会被推测填入。真实游戏全屏结算、失败/中退画面仍待样本验收。
